# l7se-do-ci-simpleTesting

A simple workflow containing some testing (i.e. to show the CI element).

- json file included to specify the testing framework to be used.
- test folder and unit tests added inside the 'website' folder
- extra javascript added to end of 'script.js' to ensure tests work (jsdom is used here --> jest is simulating the browser DOM).
- HTML, CSS AND JAVASCRIPT are all checked (i.e. syntax and linting) before quick unit tests are run).
